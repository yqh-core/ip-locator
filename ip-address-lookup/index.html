How to use the IP address lookup

  1. Open the lookup tool and enter a public IPv4 or IPv6 address.
  2. Run the lookup and review the country, region, city, ASN, ISP and timezone fields returned by the available sources.
  3. Compare the source and field-level attribution when providers disagree. IP geolocation is not GPS and should not be treated as an exact address.
  4. For network planning, use the CIDR calculator; for hostname diagnostics, use DNS or reverse-DNS lookup.

How accurate is IP geolocation?

IP geolocation databases infer approximate network locations from registration, routing and provider data. Results can differ between sources and may point to a carrier gateway, VPN exit, corporate network or ISP registration location. Use them for network context and troubleshooting, not for identifying a person's home or proving their physical presence.

Privacy and data sources

The lookup result is obtained from third-party IP geolocation services. The IP address or domain you choose to query is sent to those providers so they can return a result.
