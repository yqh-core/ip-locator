IP Address Documentation

A practical guide to IP addresses, network ownership and geolocation accuracy

1. What is an IP address?

An Internet Protocol (IP) address is a network identifier used to route traffic between devices and services. The two address families used on the public internet are IPv4 and IPv6.

IPv4 uses 32 bits and is usually written as four decimal numbers, such as 8.8.8.8. Each number ranges from 0 to 255. IPv6 uses 128 bits and is written as hexadecimal groups, for example 2001:4860:4860::8888. IPv6 provides a vastly larger address space.

2. Public and private IP addresses

Public IP addresses are globally routable. Private addresses are reserved for internal networks and are reused by homes, offices and cloud networks. They cannot be mapped to one unique public location.

  • 10.0.0.0/8 — 10.0.0.0 through 10.255.255.255
  • 172.16.0.0/12 — 172.16.0.0 through 172.31.255.255
  • 192.168.0.0/16 — 192.168.0.0 through 192.168.255.255

Loopback addresses such as 127.0.0.1 and link-local addresses such as 169.254.0.0/16 are also not ordinary public internet endpoints.

3. CIDR notation and network ranges

CIDR describes a block of addresses using an IP address and a prefix length. For example, 8.8.8.0/24 contains 256 IPv4 addresses. A shorter prefix represents a larger block: /32 is one IPv4 address, while /24 is 256 addresses.

IP geolocation databases map address ranges to approximate locations and registered network information. This lookup tool checks an individual IP address; it is not a subnet scanner or a source of authoritative routing records.

4. What does an ASN tell you?

An Autonomous System Number (ASN) identifies a network that exchanges routing information with other networks. ASN and organization fields can help identify the network that announces an address range, but they do not prove who is using a particular device or connection.

For example, AS15169 is associated with Google and AS13335 with Cloudflare. Network ownership and service-provider relationships can change, so treat registry data as context rather than a real-time identity check.

5. How IP geolocation works

IP geolocation providers maintain databases that associate address ranges with estimated countries, regions, cities, coordinates and time zones. The result is a database estimate, not GPS positioning or a measurement of a person's physical location.

  • Country-level estimates are often more reliable than city-level estimates.
  • VPNs and proxies usually show the exit server's network or location.
  • CDNs and cloud services may show an edge location or data-center network.
  • Mobile networks can route traffic through gateways far from the device.

6. IPv6 coverage and accuracy

This tool accepts IPv4 and IPv6 addresses. However, third-party databases do not always have equally complete records for every IPv6 allocation. Some IPv6 results may be available only at country or network level. An empty city field does not mean the address is invalid.

7. Data sources and privacy

When you check your own public IP, location context is supplied by Cloudflare with the request. When you enter another IP address, the lookup uses public data services such as ipwho.is and ipinfo.io. The result identifies the source used for that lookup.

Your entered IP is sent to the selected data provider so it can be looked up. The site does not store your query history on its own server. Review the privacy policy for details about advertising and third-party processing.
