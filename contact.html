问题、建议与数据纠错

🔧 我该通过哪种方式联系？

🐛

查询报错 / 查不到结果

请通过 DigDevBox 联系页 反馈，附上你查询的 IP、时间和页面提示。这是最快能得到处理的渠道。

🗺️

归属地数据不准

IP 库的数据由第三方维护，若某条数据明显错误，请通过上方渠道说明「查询结果 / 你认为正确的归属地 / 判断依据」，我们会评估后调整数据源优先级。

💡

功能建议

想要批量查询、IPv6 支持、导出 CSV 等能力？欢迎在 Issues 里提出，我们会按需求热度排期。

🔒

隐私与合规

涉及个人数据、删除请求或合规问询，请先阅读隐私政策，再通过 Issues 联系我们。

⏱️ 响应时间

本站是个人维护的免费工具，并非商业客服团队。我们通常会在 1–7 个工作日内回复 GitHub Issues，但不保证对所有请求作出响应，也不提供电话或即时通讯支持。

📋 提 issue 前请确认

  • 你是否在看常见问题，那里已经覆盖了大部分查询结果异常的原因。
  • 你查询的 IP 是否是公网 IPv4 地址。本工具不支持内网地址（10.x / 172.16.x / 192.168.x）与保留地址。
  • 你的网络是否能正常访问本工具——若页面一直转圈，通常是三个数据源同时不可用，可稍后重试。
