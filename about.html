关于本站

一个纯在前端跑的 IP 归属地查询工具

它解决什么问题

拿到一个 IP，想知道它大概在哪儿、属于哪家运营商——排查异常访问、看服务器出口、判断日志里某个请求的来源时，这是很常见的一步。这个工具把这件事做成一个输入框：贴进去，回车，看结果。不需要注册，也不存你的查询记录。输入 8.8.8.8 这类公开 IP 试试，或直接点「查询我的 IP」看你自己的公网出口。

能查到哪些信息

  • 地理位置：国家、省份 / 地区、城市，以及经纬度坐标（坐标带地图链接，可在地图上核对）。
  • 网络归属：运营商（ISP）、组织名、ASN（自治系统号，例如 AS15169 = Google、AS4837 = 联通 CHINA169 骨干网）。
  • 其他：时区、邮编。

数据从哪来，要多准

本站自己不做 IP 定位——数据依次取自 ipapi.co、ipwho.is、ipinfo.io 三个公开服务，任意一个可用就返回，再把它们的字段统一归一化后展示。这层多源自动降级是为了抗单个服务限流或抖动。

要知道的边界：IP 归属地反映的是分配该地址的运营商 / 机构的大致位置，不是物理精确地址。走 VPN、代理或 CDN 时，查到的是出口 / 节点位置而非终端真实位置。把它当「大概在这个城市、属于这家运营商」来用是可靠的，指望定位到门牌号则会失望。

隐私

你查询的 IP / 域名会被发送给上述第三方数据服务（这是查询本身绕不开的一步）。除此之外，本站不在服务器端存储你的输入或查询记录，也不自设 Cookie。页面挂载了 Google AdSense 广告，相关的 Cookie 与数据处理在隐私政策里逐条说明。

技术栈

纯静态：HTML5 + CSS3 + 原生 JavaScript，无后端、无数据库。托管在 Cloudflare Pages，全站 HTTPS。

反馈

字段有错、某个数据源挂了、或想加什么能力，请通过联系页告诉我们；附上你查的 IP 和实际看到的结果，处理会快很多。
