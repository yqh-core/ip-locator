❓ 常见问题

关于 IP 查询，你大概率想问这些

为什么查出来的城市和我实际位置不一致？

这是 IP 地理定位最常见的误解。IP 地址归属于运营商的网络设备，而不是你本人。以下情况都会导致偏差：

  • 你使用了 VPN 或代理，出口节点在别的城市甚至别的国家；
  • 你用的是移动网络（4G/5G），出口通常在省会或区域核心节点；
  • 运营商使用了 NAT 或地址池跨市复用；
  • IP 归属关系近期变更过，但 IP 库尚未更新。

一般来说，IP 定位能到城市级已属正常，省级更可靠。想深入了解原理，请看IP 知识文档。

能定位到街道或门牌号吗？

不能，任何声称能用 IP 定位到街道的服务都不可信。IP 定位依赖的是 IP 地址段的注册与分配记录，其颗粒度由运营商发布的 WHOIS 数据决定，最细通常只到城市。要获得精确位置，必须由设备本身授权（如浏览器地理定位 API 或手机 GPS）。

什么是 ASN？它有什么用？

ASN（Autonomous System Number，自治系统号）是互联网上每个独立网络运营实体的编号。比如 AS15169 是 Google，AS4837 是中国联通 CHINA169 骨干网。通过 ASN 你可以判断一个 IP 属于哪家运营商或云厂商，这在排查网络问题、识别爬虫来源、判断 CDN 节点时非常有用。

为什么查询内网地址会失败？

内网地址（10.x.x.x、172.16.x.x–172.31.x.x、192.168.x.x）是 RFC 1918 规定的私有地址段，在全球被无数局域网重复使用，不存在唯一归属地，因此无法查询。想查自己在互联网上的地址，请点击首页的「查询我的 IP」。

我的查询会被记录下来吗？

本工具本身不保存你的查询历史，也不设置追踪 Cookie。需要注意两点：一是你的访问 IP 会像访问任何网站一样出现在托管方的访问日志中；二是查询请求会经过第三方 IP 库，它们会看到被查询的 IP。详细说明见隐私政策。

支持 IPv6 吗？

目前支持 IPv4 查询。IPv6 已在开发计划中，主要难点在于第三方数据源对 IPv6 的覆盖度参差不齐。你可以关注关于页面的更新日志获取进展。

为什么有时查询很慢或直接失败？

本工具会并发请求多个 IP 库，取最先返回结果。如果你所在网络到这些服务的链路不稳定，或这些服务对当前出口 IP 触发了限流，就可能出现超时。遇到这种情况请稍后重试；若持续失败，欢迎到联系页面反馈。

可以批量查询吗？有 API 吗？

本站提供同源的 /api/ip 端点（/api/ip?ip=8.8.8.8），返回 JSON 结果，可用于轻量调用。请勿用于高频批量场景，否则可能触发上游限流。批量功能正在规划中。

查询结果可以用于风控或法律用途吗？

不建议作为唯一依据。IP 定位是概率性推断，且可被代理、VPN、云主机轻易改变。在风控场景中它只适合作为辅助信号，在法律场景中通常不具备证明力。详见服务条款。
