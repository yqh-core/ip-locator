🔒 隐私政策

我们重视并保护您的隐私

最后更新时间：2026 年 11 月 18 日（数据源改为只使用已核验许可的路径，缓存时长与页面行为对齐）

📋 隐私政策概述

这份政策说明：你用本站查询 IP 时，哪些数据会被处理、由谁处理（本站、第三方 IP 数据服务、广告商各自做什么）、保留多久，以及你能怎么管理它们。

📊 信息收集

实际会碰到的数据：

  • 你输入的地址：查指定 IP 时，这个地址会被用来向数据源要结果，并按下面的规则短暂放进边缘缓存。
  • 你的出口地址：打开首页或点「看我的出口地址」时，Cloudflare 能看到这次连接的 IP，并用边缘节点自带的地理信息回答。这条路径不另调第三方 IP 库。
  • 本站不另建一份「技术档案」：页面不会为了改进服务去采集操作系统清单。托管方和广告脚本仍会按它们自己的规则看到浏览器请求，这和访问任何网站一样。

🎯 信息使用

我们使用收集的信息用于：

  • 提供IP归属地查询服务
  • 改善和优化用户体验
  • 分析服务使用情况，提升服务质量
  • 维护网站安全和防止滥用

🔐 信息保护

传输走 HTTPS。查询内容不写入账号数据库。它会在边缘缓存里留一段较短的时间，期限写在下面，不是永久保存。

🌐 第三方服务

查你自己的地址时，位置信息取自 Cloudflare 边缘节点随请求附带的地理数据，不为自查调用第三方 IP 库。查你输入的其他地址时，请求由本站边缘函数转发到 ipinfo.io。ipwho.is 的商用条款没有一手核验，2026-11-18 起不再调用。

  • 被查询的地址会发给 ipinfo.io，对方可能按自己的政策记录这次请求。建议同时看 ipinfo.io 隐私政策。
  • 你若点「查反向域名」或用页面上的 DNS 工具，浏览器会直接向 Cloudflare 的公共 DNS（1.1.1.1）发查询，不经过本站服务器。
  • 你若点「加载街道图」，浏览器会向 OpenStreetMap 请求地图瓦片，坐标会发给对方。不点就不会发。
  • 本站托管于 Cloudflare Pages。和访问任何网站一样，出口 IP 会出现在托管方的访问日志里。

🍪 Cookies、分析与广告

本站已接入 Google AdSense 广告。Google 及其广告合作伙伴会在你的浏览器中使用 Cookie（含第三方 Cookie，如 DoubleClick Cookie），用于：投放广告、限制同一广告的重复展示次数、以及根据你的浏览行为投放个性化广告。

你可以随时选择退出个性化广告，任选其一：

  • 访问 Google 广告设置 关闭基于兴趣的个性化广告；
  • 使用 aboutads.info（或其他地区的同类机制）退出基于兴趣的广告。

注意：退出个性化广告不等于不再看到广告，只是广告不再基于你的兴趣定向。

除广告 Cookie 外，本站用浏览器本地存储记住深色或浅色、语言，以及你在这台设备上查过的地址。这些不回传到业务数据库。本站没有接入 Google Analytics。页面会向 metrics.digdevbox.com 发送三类已有计数：访问、开始查询、查询成功。计数里没有 IP，也没有你查询的内容。测量客户端保持冻结，这次没有加事件，也没有改身份或存储方式。

你可以做的事

你可以随时停用这个网站。浏览器里的主题、语言和查询记录，在站点数据里清掉就行。想知道某条信息还在不在，或认为缓存里不该留着你查过的地址，通过联系页写过来。边缘缓存没有单条删除按钮，只能等它到期，或等我们更换缓存版本让旧条目一起失效。

⏳ 数据保留期限

  • 查询的 IP 地址：它在请求处理过程中被用于获取查询结果。本站不把它写入业务数据库，也不建立与账号关联的「查询历史」。但它不是用完即弃——它会按下条所述留在边缘缓存里一段时间。
  • 查询结果缓存：为少打重复请求，本站按被查询的 IP 生成缓存键（键中包含该 IP 原文），并把结果写入边缘缓存：查询指定 IP 最长保留 1 小时，查询自身 IP 最长保留 5 分钟，到期自动失效。同一节点上对同一 IP 的后续请求会命中同一条目。本站能用 TTL 和缓存键版本号让它整体过期，但没有单条手动清除入口。
  • 浏览器缓存：成功的指定 IP 响应带 Cache-Control: public, max-age=3600，自身 IP 响应是 max-age=300。错误响应是 max-age=0，避免一次失败被缓存住。
  • 访问日志：由托管方（Cloudflare Pages）按其自身策略保留，本站不额外导出或长期留存。
