🔒 隐私政策

我们重视并保护您的隐私

最后更新时间：2026年9月

📋 隐私政策概述

感谢您使用IP归属地查询工具。我们深知个人隐私的重要性，并致力于保护您的隐私安全。本隐私政策旨在帮助您了解我们如何收集、使用和保护您的信息。

📊 信息收集

我们收集的信息：

  • IP地址：当您使用我们的服务查询IP归属地时，您输入的IP地址将被临时处理以提供查询结果。
  • 访问者IP：当您点击"查询我的IP"功能时，我们会获取您当前的公网IP地址以提供查询服务。
  • 技术信息：我们可能收集浏览器类型、操作系统、访问时间等基本技术信息，用于改进服务质量。

🎯 信息使用

我们使用收集的信息用于：

  • 提供IP归属地查询服务
  • 改善和优化用户体验
  • 分析服务使用情况，提升服务质量
  • 维护网站安全和防止滥用

🔐 信息保护

我们采取以下措施保护您的信息安全：

  • 所有查询请求通过HTTPS加密传输
  • 我们不会永久存储您查询的IP地址信息
  • 查询记录仅用于临时处理，不会长期保存
  • 我们采用行业标准的安全措施保护数据

🌐 第三方服务

本工具的 IP 地理位置数据来自以下第三方数据源，并采用多源并发问询、任一可用即返回的方式工作：

  • ipapi.co
  • ipwho.is
  • ipinfo.io

其中部分查询会经由本站自建的服务端代理转发。这意味着：

  • 被查询的 IP 地址会发送给上述第三方数据源，它们各自可能记录该请求；
  • 这些数据源拥有各自独立的隐私政策，我们无法控制其数据处理方式，建议您一并查阅：ipapi.co 隐私政策、ipinfo.io 隐私政策；
  • 本站托管于 Cloudflare Pages，与任何网站一样，访问者的 IP 会出现在托管方的访问日志中。

🍪 Cookies、分析与广告

本站当前没有接入任何统计或广告脚本，也不设置用于追踪用户的第三方 Cookie。我们仅使用浏览器本地存储（localStorage）保存界面偏好，该数据只存在于您的设备上，不会回传服务器。

未来本站可能会引入以下内容，届时本页面会同步更新：

  • 访问统计：如 Google Analytics（GA4），用于了解哪些功能被真正使用。这类工具会通过 Cookie 采集匿名访问数据。
  • 广告服务：如 Google AdSense。Google 及其广告合作伙伴会使用 Cookie（含第三方 Cookie，如 DoubleClick）来投放广告、限制同一广告的重复展示次数，以及根据您的浏览行为投放个性化广告。

您可以通过以下方式管理广告个性化：

  • 访问 Google 广告设置 关闭个性化广告；
  • 通过浏览器设置清除或阻止第三方 Cookie；
  • 使用 aboutads.info（或其他地区的同类机制）退出基于兴趣的广告。

👤 用户权利

您拥有以下权利：

  • 随时停止使用我们的服务
  • 清除浏览器中的本地存储数据
  • 要求了解我们如何使用您的信息
  • 要求删除我们可能保留的任何个人信息

⏳ 数据保留期限

  • 查询的 IP 地址：仅在处理请求的那一刻使用，不写入数据库，不保存查询历史。
  • 查询结果缓存：为提升响应速度，查询结果会在边缘节点临时缓存。查询指定 IP 的结果最长缓存 24 小时，查询自身 IP 的结果最长缓存 5 分钟，到期自动失效。
  • 访问日志：由托管方（Cloudflare Pages）按其自身策略保留，本站不额外导出或长期留存。

🔄 隐私政策更新

我们可能会不时更新本隐私政策。重大变更时，我们会在网站上发布通知。建议您定期查看本页面以了解最新的隐私保护措施。

📧 联系我们

如果您对本隐私政策有任何疑问或建议，请通过以下方式联系我们：

  • 访问我们的 联系页面，按问题类型选择对应渠道
  • 或在 GitHub Issues 提交反馈

重要提示：使用本网站即表示您同意本隐私政策。如果您不同意本政策的任何内容，请停止使用我们的服务。
