这个工具能查到什么

输入任意 IPv4 地址，即可查询它的归属地信息：国家/地区、省份/州、城市、邮编、 ASN（自治系统号）、运营商（ISP）、所属组织、经纬度、时区，以及地理位置地图链接。 也可以点击「查询我的IP」直接查看你当前网络出口 IP 的归属信息。

数据来源与精度说明

本工具依次尝试多个免费 IP 归属地数据库，任一可用即返回结果，单一数据源不可用时 自动降级到下一个。查询请求会经本站服务器转发完成（用于缓存与限流保护，本站不在 服务器端存储你的查询内容）。定位精度以城市级为主：IP 归属数据库反映的是运营商 注册地与骨干网接入点，不一定等于设备的物理位置；不同数据源之间也可能存在差异， 结果仅供参考。

常见问题

支持查询哪类 IP 地址？

当前支持 IPv4 格式的公网地址查询（如 8.8.8.8）。

我的查询会被记录吗？

查询请求经本站服务器转发（用于缓存与限流保护），本站不在服务器端存储你的查询内容。结果数据来自第三方 IP 数据服务。

为什么不同网站的 IP 归属结果不一样？

各网站使用不同的 IP 归属数据库，更新时间与覆盖范围不同，因此结果可能存在差异。本站采用多数据源自动降级，并在结果中如实返回当前可用源的输出。
