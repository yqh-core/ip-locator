代理和 VPN

不判断

这里不会打勾，也不会打叉。本站没有接入已核验可商用的威胁情报，所以不告诉你「这是代理」或「这是 VPN」。本工具不判断、也不输出使用者属于住宅网络、移动网络还是数据中心。

你能当作线索的，是上面的登记组织和地址类别。如果你开了代理，卡片上的地址是出口，不是你人在的城市。

一次核对多个地址

把日志里的地址贴进来，每行一个，逗号也可以。一次最多 20 个：再多就会把上游额度打满，对别人也不公平。查询在你的浏览器里逐个发出，本站不保存这份列表。

子网计算

输入 CIDR 或单个 IP，算出网络地址、掩码、可用范围。IPv4 和 IPv6 都在你的浏览器里算完，不发出请求。

DNS 和反向解析

查 A、AAAA、MX 这些记录。输入 IP 会自动做 rDNS。数据来自 Cloudflare 1.1.1.1，浏览器直连，不经过本站。

    这个页面能帮你做什么
    
            
    打开就看到自己的出口 IP。想核对服务器、日志或邮件头里的地址，把 IPv4 或 IPv6 贴进输入框。旁边可以算子网、查 DNS，也能一次核对一小批地址并导出。
    
            
    数据从哪来
    
            
    查你自己的地址时，用 Cloudflare 边缘节点随请求附带的地理信息，不再调用第三方库。查你输入的其他地址时，请求会转到 IPinfo。IPinfo 免费层可以商用，但要求署名，所以结果下方有链接。ipwho.is 的商用条款没能核到一手说明，2026-11-18 起不再调用。ipapi.co 的免费计划不用于生产，仍然不调用。
    
            
    什么时候用它
    
            
      
                
    • 看自己的出口：开了代理却不确定有没有生效时，先看卡片上的地址和城市。
      • 
                
    • 对一下日志：把陌生 IP 贴进来，看登记组织和 ASN。这是线索，不是结论。
      • 
                
    • 划一段网：用子网计算看掩码和可用地址。域名和反向解析用DNS 查询。

    常见问题
    
            
    
                支持哪些地址？
                
    公网 IPv4 和 IPv6 都可以，例如 8.8.8.8 或 2001:4860:4860::8888。IPv6 的登记覆盖参差，有的只能到国家。私有地址没有全球唯一归属。
    
            
    
            
    
                查询会被记下来吗？
                
    本站不把查询做成账号历史。指定地址的结果会在边缘缓存里留最多 1 小时，缓存键里含有这个 IP，到期自动失效，没有单条删除按钮。细节在隐私政策。
    
            
    
            
    
                为什么和别的网站不一样？
                
    各家用的登记库不同，更新时间也不同。本站会在结果下写出这次是谁应答的，你可以用这个名字去对照。
    
            
    
            
    
                能导出、能批量吗？
                
    单条结果可以复制摘要、导出文本或 JSON。批量一次最多 20 个，可以复制或下载 CSV。列表只在这台浏览器里处理。
