    这个工具能查到什么
    
            
    
                输入任意 IPv4 或 IPv6 地址，即可查询它的归属地信息：国家/地区、省份/州、城市、邮编、
                ASN（自治系统号）、运营商（ISP）、所属组织、经纬度、时区，以及地理位置地图链接。
                也可以点击「查询我的IP」直接查看你当前网络出口 IP 的归属信息。IPv6 的归属覆盖度因数据源
                与地址段而异，部分地址可能仅能精确到国家级。
            
    
            
    数据来源与精度说明
    
            
    
                本工具分两条路径提供归属数据：查询您自己的 IP 时，使用的是 Cloudflare 边缘节点
                随请求附带的地理信息，不调用任何第三方数据库；查询您手动输入的 IP 时，会同时向
                ipwho.is、
                IPinfo
                等公开 IP 库发起查询，先给出可用结果的应答。查询请求经本站服务器转发（用于缓存与
                限流保护，本站不在服务器端存储你的查询内容，缓存为不超过 1 小时的短周期技术缓存）。
                结果下方会标出本次实际应答的数据源、是否命中缓存，并附应答方的数据许可/署名链接
                （IPinfo 免费层按 CC BY-SA 要求署名）。定位精度以城市级为主、因数据源而异：IP 归属
                数据库反映的是运营商注册地与骨干网接入点，不一定等于设备的物理位置；不同数据源之间
                也可能存在差异，结果仅供参考。
            
    
            
    常见场景
    
            
      
                
    • 查本机出口 IP：点击「查询我的IP」，一键查看当前网络出口 IP 的归属地与运营商登记信息。
      • 
                
    • 排查异地登录：账号出现陌生登录地时，把日志里的 IP 填入「查询框」核对归属与 ASN。归属是登记信息与城市级估算，只作排查线索，不作唯一判定依据。
      • 
                
    • 确认服务器归属：把服务器公网 IP 填入「查询框」，核对 ASN 与组织字段是否与预期一致。
      • 
                
    • 划分子网：用「CIDR / 子网计算器」算网络地址、掩码、广播与可用主机范围；域名解析与 IP 反查见「DNS / rDNS 查询」。
      • 
            
    
            
    常见问题
    
            
    
                支持查询哪类 IP 地址？
                
    支持 IPv4 与 IPv6 格式的公网地址查询（如 8.8.8.8 或 2001:4860:4860::8888）。IPv6 的归属覆盖度因数据源与地址段而异，部分地址可能仅能精确到国家级。
    
            
    
            
    
                我的查询会被记录吗？
                
    查询请求经本站服务器转发（用于缓存与限流保护），本站不在服务器端存储你的查询内容。结果数据来自第三方 IP 数据服务。
    
            
    
            
    
                为什么不同网站的 IP 归属结果不一样？
                
    各网站使用不同的 IP 归属数据库，更新时间与覆盖范围不同，因此结果可能存在差异。本站会向多家数据库取先给出的可用结果，并在结果下方标出本次实际应答的数据库，你可以据此判断这条结果出自哪一家。
    
            
    
            
    
                可以查看原始 JSON、客户端信息或查询历史吗？
                
    可以。结果下方提供「原始 JSON」视图，展示本次归一化字段（含数据来源与缓存态）并可一键复制；「你的客户端信息」面板在本机读取浏览器与设备自报信息（不上传）；「查询历史」仅存于本机浏览器，点击即可重查，可随时清空。
    
            
    
            
    
                CIDR / 子网计算器能算什么？
                
    输入 CIDR（如 192.168.1.0/24）或单个 IP，即可算出网络地址、子网掩码、通配符掩码、广播地址、首个/末个可用地址、地址总数与可用主机数，并按 RFC 标注地址分类（私有/环回/链路本地/公网等）。支持 IPv4 与 IPv6（含 /31 点对点与 RFC 5952 压缩格式），计算完全在本机浏览器完成，不发出任何请求。
    
            
    
            
    
                DNS / rDNS 查询的数据从哪里来？
                
    来自 Cloudflare 1.1.1.1 的 DNS-over-HTTPS 公共解析服务，由浏览器直连查询，不经本站服务器。支持 A/AAAA/CNAME/MX/TXT/NS/SOA/CAA 记录；输入 IP 会自动构造 in-addr.arpa / ip6.arpa 反查 rDNS（PTR）。域名不存在时如实返回 NXDOMAIN。
