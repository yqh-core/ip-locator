# IP Locator 改造记录

日期：2026-11-18。对照复盘包 R1（报告 01–04、台账 01–06）。本文件只记事实。

## 对标结论

- 语言与市场：复盘包把本站定为 `MAINTAIN_LOCAL` / 中文存量。2026-11-11 快照 7 日 185 次访问，中国+香港 91%，美国 6.5%，百度是主要外部来源。这不是欧美需求证据。页面保持中文，不按浏览器语言自动切英文，不新增英文 SEO 页。
- 竞品（IPinfo、whatismyipaddress、iplocation.net、ipapi.co、ip.sb）首屏都是「你的地址 + 位置卡片 + 地图 + 网络字段」。本站原先要把结果藏到查询结束，并预留大块空白。
- 代理 / VPN / 威胁情报：没有已核验可商用的情报源。按文案口径和许可边界，不做「是 VPN」这类判断，页面写明不判断。地址类别只按 RFC 数学分类。
- 数据源：自查仍只走 Cloudflare `request.cf`。指定地址只请求 ipinfo.io（免费层可商用，须署名）。ipwho.is 商用条款没有一手核验，已停止调用。ipapi.co 继续不调用。

## 改动

- 首页改成打开即见出口地址卡片：位置、ASN、登记组织、时区当地时间、经纬网示意。街道图需点一下才向 OpenStreetMap 要瓦片。
- 单条结果可复制摘要、导出文本和 JSON。批量一次最多 20 个，浏览器内逐个查，可复制或下载 CSV。列表不上传保存。
- 子网计算、DNS / rDNS 留在首页。文档增加接口一节（`/api/ip`，一次一个地址）。
- 国家名用中文展示，`country_original` 仍是上游国家码。
- 指定地址边缘缓存 1 小时，自身地址 5 分钟；浏览器 `Cache-Control` 与此对齐，错误响应不缓存。隐私页原先写的 24 小时已改成与代码一致。
- 教程里「云厂商 ASN 就是爬虫」已删除。条款和教程改为同时支持 IPv4 / IPv6。
- 测量脚本未改。事件仍是 `visit`、`tool_start`、`tool_success`。没有新分析服务。
- 没有新的 SEO URL。`sitemap.xml` 只更新了 lastmod。

## 三轮复盘

### 第一轮

对照竞品差距、阻塞清单和现有门禁，先改这些：

- 结果区 `min-height` 690px / 移动端 1341px，查询前卡片 `display:none`。首屏留白，也不立刻看到自己的地址。改为卡片常驻。
- `ipwho.is` 仍在服务端和浏览器兜底里。许可未核验，从调用清单移除。
- 隐私页写指定 IP 缓存 24 小时，代码已是 1 小时。自身 IP 的响应却带 `max-age=3600`。改为指定地址 1 小时、自身 5 分钟、错误 0。
- 教程把同一云厂商 ASN 说成爬虫；教程和条款仍写只支持 IPv4。已改。
- 没有批量、没有导出、接口说明散落且缓存时长过时。已补在现有首页和文档，没有新页面。

### 第二轮

用桌面和 390px 宽页面看实际渲染：

- 国家名是英文长句，和「复制」挤在一起。改为中文国名，登记码单独一行。
- 降级文案「已改用可用来源」看不出到底是谁应答。改为写明哪条线路没有应答。
- JSON 区块还没出现时，历史被两列网格挤在半宽。结果出现前改为单列。
- 窄屏站内导航把「关于」甩到下一行。改为单行横滑。
- 批量主按钮和查询按钮不够好认。批量开始改为实心主按钮。

### 第三轮

再对一遍差距矩阵、阻塞项和门禁，没有新的产品缺口要在本次未授权范围内补：

- 威胁情报仍不做。原因是没有可商用数据源，不是漏做按钮。
- 批量不上服务端批接口，避免把 ipinfo 免费额度打满。
- `js/analytics.iife.js` 未改；没有新事件、没有新的身份或存储键。
- 文案门禁、许可门禁、18 项单测、`node scripts/build.mjs` 通过。本仓库没有 TypeScript。
- 本地静态服务没有 Pages Function，自查会降级到 ipinfo.io。生产自查仍由单测锁在 `cloudflare-edge` 且零第三方调用。
- 未部署生产，未改 DNS，未接支付。
