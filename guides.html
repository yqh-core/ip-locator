IP Lookup Guides

Practical steps for checking an address and interpreting the result

1. Look up a public IP address

  1. Open the IP Locator homepage.
  2. Paste a public IPv4 or IPv6 address into the lookup field.
  3. Select Lookup or press Enter.
  4. Review the country, region, city, network organization, ASN and data-source label when available.

Try a well-known public address such as 8.8.8.8 to see the result format. Private and reserved addresses do not have a unique public geolocation.

2. Check your own public IP

Choose Find my IP on the homepage. The page displays the public address observed at the Cloudflare edge and the available location context. If you are connected through a VPN, corporate proxy or privacy relay, the result usually describes that exit path rather than your device's local network.

3. Understand the result fields

  • Country / region / city: an estimate from the provider's IP database.
  • ISP / organization: the registered network or organization associated with the range.
  • ASN: the autonomous system announcing the route.
  • Coordinates: approximate map coordinates; they are not a street address.
  • Time zone / postal code: supplementary database fields that may be missing or approximate.

4. Investigate a VPN, proxy or CDN address

Look at the organization and ASN alongside the location. A cloud, hosting or security-network provider may indicate that the address belongs to an intermediary or edge service. It does not, by itself, prove that a person is using a VPN or identify the end user.

5. Troubleshoot an unexpected location

  • Check whether the address is public rather than private or reserved.
  • Compare the result with another reputable IP database.
  • Check whether the address belongs to a mobile carrier, VPN, proxy or CDN.
  • Remember that providers update allocation data on different schedules.

Different databases can legitimately return different city or region estimates for the same address.

6. Use IP geolocation responsibly

IP geolocation is an estimate and is usually only accurate to the city level. It is not the actual physical location of the device or user. Treat results as a reference only; an ISP or ASN record does not necessarily identify the actual service provider for a connection.

Use IP lookup as a troubleshooting signal, not as proof of a person's identity or exact location. Do not rely on a single IP field for fraud decisions, access control or legal conclusions. Combine it with other verified signals and your own review process.
